# Herder

Herder runs coding work that is durable, verified, and proportionate. The main agent chooses how much orchestration a task needs, from a single writing step to a fan-out workflow; every run is journaled so it survives crashes and new sessions; success is computed from real checks; and nothing reaches your branch until you approve delivery.

Herder is under construction. This README is completed together with its commands and tools.

## Requirements

- Git 2.38 or newer.
- Node >=22.19.0 and Pi >=1.3.0.
