symbols-nerd-font-mono-pua.woff2 is "Symbols Nerd Font Mono" from Nerd Fonts v3.5.1
(https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1, NerdFontsSymbolsOnly.tar.xz,
sha256 01172f37db8543edb102e5cb5c64101c9f4686630804d49b419aa07b23a69996), file
SymbolsNerdFontMono-Regular.ttf, subset with fontTools 4.68.0 to its Private Use Area code points
(U+E000-F8FF, U+F0000-FFFFD; every icon set below, the 14 non-PUA symbols dropped) and compressed to WOFF2:

  pyftsubset SymbolsNerdFontMono-Regular.ttf --unicodes=U+E000-F8FF,U+F0000-FFFFD --flavor=woff2 \
    --layout-features='*' --notdef-outline --name-IDs='*' --name-languages='*'
